1. 서비스 개요

1.1서비스 정의

다왔어(Wakepoint)는 목적지를 지정해 두면, 사용자의 기기가 해당 목적지 반경에 진입하는 순간 전체화면 알람(소리·진동)으로 깨워주는 위치 기반 도착 알람 앱이다. 대중교통 이동 중 잠들거나 딴짓을 하다 내릴 곳을 지나치는 문제를 해결한다.

1.2핵심 가치

  • 놓치지 않는 알람 — 화면이 꺼져 있거나 다른 앱 사용 중, 잠금화면 상태에서도 전체화면 알람이 즉시 뜬다.
  • 서로 깨워주는 관계 — 친구에게 권한을 받으면 친구의 기기에 도착 알람을 대신 설정해줄 수 있다 ("지켜봐 주는 친구").
  • 위치 프라이버시 — 위치 판정과 알람 발동은 전적으로 기기 로컬에서 수행한다. 서버·푸시·로그 어디에도 위치, 근접, 도착 여부를 기록하지 않는다.
  • 오프라인 내성 — 알람 생성·수정·삭제는 로컬 우선으로 즉시 반영되고, 네트워크 복구 시 서버와 자동 동기화된다.

1.3타깃 사용자

  • 대중교통(버스·지하철·기차)에서 하차 지점을 놓치기 쉬운 통근·통학자, 여행자
  • 가족·연인·친구가 목적지에 잘 내리도록 챙겨주고 싶은 사용자 (대리 알람 설정)

1.4핵심 사용자 시나리오

시나리오흐름
S1. 내 도착 알람지도에서 목적지 선택(탭/검색/음성) → 별칭·반경·소리·진동 설정 → 알람 저장 → 이동 중 백그라운드 위치 추적 → 반경 진입 시 전체화면 알람 → "알람 끄기"
S2. 친구 깨우기친구 검색/초대 → 친구 수락 → 알람 설정 권한 요청 → 친구가 권한 수락 → 친구에게 알람 전송 → 친구 기기에 FCM으로 알람 동기화 → 친구 기기가 로컬에서 위치 판정 후 알람 발동
S3. 반복 구간 알람알람의 "계속 유지" 활성화 → 도착해 울린 뒤에도 꺼지지 않음 → 반경을 벗어나면 재무장(REARM) → 재진입 시 다시 발동

2. 서비스 구조 및 화면 흐름

2.1정보 구조 (IA)

  • 진입: 스플래시 → (비로그인) 로그인 · 회원가입 / (로그인) 메인
  • 메인 하단 탭 4개: 지도(home) · 알람(alarms) · 친구(friends) · 마이(profile)
  • 서브 화면: 회원가입(sign-up), 사운드 목록(sound-list — 전역 기본 사운드 또는 특정 알람 사운드 편집)
  • 독립 화면: 도착 알람 전체화면(AlarmAlertActivity — 잠금화면 위 표시)

2.2인증 라우팅 규칙

  • 세션 확인 중에는 화면 전환을 보류하고, 저장된 세션으로 즉시 분기한다(토큰 검증·갱신은 백그라운드, stale-while-revalidate).
  • 스플래시는 상태 확정 즉시 벗어난다. 로그인 상태로 인증 화면에 있으면 홈으로, 비로그인 상태로 인증 영역 밖에 있으면(세션 만료·로그아웃) 로그인 화면으로 보낸다.
  • 그 외에는 사용자가 보던 화면을 절대 이동시키지 않는다(권한 설정 왕복, 다크모드 전환, 액티비티 재생성 등에서 첫 화면으로 튕기지 않음).

2.3백그라운드 구성요소

구성요소역할
위치 추적 포그라운드 서비스활성 알람이 1개 이상이면 상시 위치 확인(5초 간격), 도착 판정 및 알람 발동
알람 실행 서비스전체화면 알람 표시, 소리·진동 재생, 최대 30초 후 자동 정지
FCM 수신 서비스친구 알람 전송 등 서버 변경 신호 수신 → 알람 재동기화
주기 동기화 워커30분 주기(네트워크 연결 시) 서버 알람 catch-up 동기화
부팅 리시버재부팅·앱 업데이트 후 활성 알람의 위치 추적 자동 재개

3. 기능 정의

우선순위: P0 = 핵심(없으면 서비스 불성립) · P1 = 주요 · P2 = 보조. 모든 항목은 현재 구현 완료 상태이다.

3.1인증 (AUTH)

ID기능정의우선
AUTH-01이메일 로그인이메일+비밀번호 로그인. 빈 값 검증("이메일과 비밀번호를 입력해주세요."). 처리 중 버튼 비활성.P0
AUTH-02카카오 로그인Supabase OAuth(provider=kakao)로 브라우저 인증 후 딥링크(com.wakepoint.app://auth-callback) 복귀. 프로필 닉네임·이미지 scope.P0
AUTH-03회원가입이름·이메일·비밀번호(6자 이상)·비밀번호 확인. 가입 즉시 세션 발급 시 프로필 생성 후 홈 진입, 이메일 확인 정책 시 안내 문구 노출.P0
AUTH-04비밀번호 재설정로그인 화면에서 이메일 입력 후 재설정 메일 발송.P1
AUTH-05세션 유지·자동 갱신세션을 로컬 보관, 만료 300초 전부터 refresh token으로 갱신. 401/400이면 세션 삭제 후 재로그인 유도, 일시 오류(5xx·네트워크)면 기존 세션 유지.P0
AUTH-06로그아웃서버 로그아웃 + 로컬 세션 삭제 → 로그인 화면 이동.P0

3.2지도 · 알람 생성 (MAP)

ID기능정의우선
MAP-01지도 표시·내 위치Google Map 기반. 위치 권한 허용 시 내 위치 표시 및 카메라 이동, 현재 위치가 기본 목적지. 기본 카메라: 서울시청(줌 15). 내 위치 FAB 제공(실패 시 서울시청 폴백).P0
MAP-02지도 탭으로 목적지 선택지도 탭 → 마커 표시 + 좌표→주소 역지오코딩(도로명 우선, 지번 차선, 실패 시 "지도에서 선택한 위치").P0
MAP-03장소 검색카카오 키워드+주소 통합 검색(중복 제거). 결과 선택 시 카메라 이동(줌 16)·목적지 지정.P0
MAP-04음성 검색시스템 음성인식(한국어)으로 검색어 입력("목적지를 말해주세요"). 미지원 기기는 토스트 안내.P2
MAP-05알람 설정 시트별칭(미입력 시 주소→"목적지 알람" 폴백), 반경(100m/300m/500m/1km/3km/10km, 기본 500m), 소리 on/off + 선택 사운드 표기, 진동 on/off. 저장 시 알람 탭으로 이동 + 위치 추적 동기화.P0
MAP-06생성 전 권한 게이트알람 만들기 시 알림 권한(13+)과 전체화면 알람 특수권한을 확인·요청.P1

3.3알람 관리 (ALM)

ID기능정의우선
ALM-01알람 목록·분류즐겨찾기 / 활성 알람 / 지난 알람 3개 섹션. 활성 우선, 별칭 오름차순 정렬. 발신 구분 표기(직접 설정/친구가 설정).P0
ALM-02요약 헤더활성 N개 시 "지금 N개의 알람이 지켜보고 있어요", 0개 시 "모든 알람이 꺼져 있어요".P2
ALM-03알람 편집카드 확장 후 별칭·반경·사운드·진동·반복 수정, 저장. 항목별 진행 표시.P0
ALM-04활성 on/off스위치 토글. 변경 즉시 로컬 반영 + 동기화 플래그(서버 이전 값으로 되살아나는 문제 방지).P0
ALM-05즐겨찾기별 아이콘 토글, 즐겨찾기 섹션 상단 고정(로컬 전용 설정).P1
ALM-06계속 유지(반복)한 번 울려도 꺼지지 않고, 반경 이탈 후 재진입 시 재발동(로컬 전용 설정).P1
ALM-07삭제(단건)확인 다이얼로그("삭제한 알람은 다시 복구할 수 없습니다.") 후 삭제.P0
ALM-08다중 선택 삭제롱프레스로 선택 모드 진입, 개별/전체 선택, 선택 개수 표시, 일괄 삭제 확인. 뒤로가기로 선택 모드 종료. 동기화로 사라진 알람은 선택 집합에서 자동 정리.P1
ALM-09빈 상태"아직 알람이 없어요" + "첫 알람 만들기" CTA(지도 탭 이동).P2

3.4알람 사운드 (SND)

ID기능정의우선
SND-01사운드 목록·선택기본 제공(앱 번들) / 내 알림음(녹음·가져옴·기기 알람음) 2개 섹션. 탭 시 미리듣기 + 선택 저장(체크 표시).P1
SND-02이중 스코프전역 기본 사운드(마이 > 알람 사운드 관리)와 개별 알람 사운드(알람 편집에서 진입)를 같은 화면으로 편집.P1
SND-03기기 알람음 선택시스템 알람음 피커(RingtoneManager) 연동, 선택 항목을 내 알림음에 추가.P2
SND-04오디오 파일 가져오기SAF로 audio/* 파일 가져오기(13+ READ_MEDIA_AUDIO / ≤32 READ_EXTERNAL_STORAGE 권한).P2
SND-05음성 녹음마이크 권한 후 녹음 시트(Idle→Recording→Recorded, mm:ss 표시). M4A/AAC 128kbps 44.1kHz 저장.P2
SND-06커스텀 사운드 삭제확인 후 삭제(번들 사운드는 불가). 기본값이었다면 기본값 해제.P2

3.5친구 · 대리 알람 (FRD)

ID기능정의우선
FRD-01친구 검색·요청이메일 또는 닉네임으로 검색(최소 2글자) → 요청 전송. 본인·기존 관계 요청 방지.P0
FRD-02요청 수락·거절·취소받은 요청은 수락/거절, 보낸 요청은 취소. 섹션별로 구분 노출.P0
FRD-03친구 초대카카오톡 공유(미설치 시 일반 공유 시트 폴백) / 링크 복사. 초대 문구에 내 이메일 검색 유도 + Play 스토어 링크 포함.P1
FRD-04친구 차단·삭제친구 카드에서 차단/삭제(확인 다이얼로그).P1
FRD-05알람 설정 권한"친구 기기에 알람을 대신 설정할 권한"을 요청 → 상대가 수락/거절. 상태 표기(대리 설정 가능/권한 대기/거절됨), 만료 없음(영구).P0
FRD-06친구에게 알람 보내기권한 Accepted인 친구에게만 가능. 주소 검색으로 목적지 선택 후 별칭·반경·소리·진동 설정 → 전송. 사운드는 앱 번들 사운드만 전파(개인 녹음·파일은 상대 기기 재생 불가 → 시스템 기본 알람음 폴백).P0
FRD-07수신 알람 동기화친구가 보낸 알람은 FCM 신호 → 수신자 기기가 서버에서 알람을 내려받아 로컬 등록, 위치 추적 시작.P0

3.7알람 발동 엔진 (TRG)

ID기능정의우선
TRG-01백그라운드 위치 추적활성 알람 ≥1개면 포그라운드 서비스 시작(고정밀, 5초 간격·최소 2초), 0개면 자동 중단. 상시 알림 "활성 알람 N개를 확인하고 있어요"(저중요도).P0
TRG-02도착 판정거리 ≤ 반경 + GPS 정확도 버퍼(정확도/1000, 최대 50m). 추가로 직전→현재 이동 선분과 목적지의 최근접 거리 판정(간격 ≤300초·선분 ≤10km 조건)으로 고속 이동 시 반경 통과 누락 방지.P0
TRG-03발동·재무장 상태기계반경 진입+미발동 → FIRE / 반복 알람이 반경 이탈+발동 상태 → REARM / 그 외 NONE. 서비스 시작 직후 현재 위치 1회 즉시 평가(이미 반경 안인 경우 포착).P0
TRG-04전체화면 알람잠금화면 위·화면 꺼짐에도 알람 화면 표시(전체화면 알림 + 오버레이). 목적지 별칭·주소 표시, "알람 끄기" 버튼. 소리(USAGE_ALARM, 반복, 실패 시 시스템 알람음 폴백)·진동(0/700/250/700ms 패턴) 동시 실행, 최대 30초 후 자동 정지.P0
TRG-05발동 후 처리깨움 횟수 +1. 일반 알람은 삭제 대신 비활성화(재사용 가능), 반복 알람은 활성 유지. 서버에 상태 반영.P0
TRG-06부팅·업데이트 복원재부팅/앱 업데이트 완료 시 활성 알람이 있으면 위치 추적 자동 재개.P1

4. 화면별 상세 명세

4.1스플래시

  • 로고 + 태그라인 "목적지 도착 알림의 시작".
  • 저장된 세션 즉시 평가 후 홈/로그인 분기. 네트워크 토큰 검증을 기다리지 않는다.

4.2로그인 / 회원가입

  • 구성: 이메일·비밀번호 입력, 로그인 버튼, 비밀번호 재설정 링크, 카카오 로그인 버튼, 회원가입 링크.
  • 처리 중 상태("처리 중...")로 중복 제출 방지. 오류·안내는 다이얼로그로 구분 표시.
  • 회원가입: 이름/이메일/비밀번호/비밀번호 확인 4개 필드 + 유효성 검증(§3.1 AUTH-03). 뒤로가기 지원.
  • 참고: 전화번호·생년월일·인증번호 리소스는 존재하나 MVP에서 미노출.

4.3지도 홈

  • 상단 검색바(+음성 검색 버튼), 지도 영역, 내 위치 FAB, "알람 만들기" 버튼.
  • 목적지 선택 상태: 커스텀 마커 + 해석된 주소 표기.
  • 검색 시트: 키워드 입력 → 결과 목록(장소명·주소) → 선택 시 지도 이동.
  • 알람 설정 바텀시트: 별칭 / 목적지(읽기 전용) / 반경 선택기 / 소리 토글(선택 사운드명 + "마이 > 알람 사운드 관리에서 변경" 안내) / 진동 토글 / 저장.

4.4알람 목록

  • 헤더: 제목 + 요약 + 알람 추가 버튼(지도 탭 이동).
  • 컴팩트 카드: 상태 점, 별칭, 주소, "반경 X · 사운드명" 메타, 즐겨찾기 별, 활성 스위치.
  • 탭 → 편집 카드 확장(별칭·반경·사운드·진동·계속 유지·저장·삭제) / 롱프레스 → 다중 선택 모드(전체 선택·N개 선택·일괄 삭제).

4.5사운드 목록

  • 섹션: 기본 제공 사운드 / 내 알림음. 각 항목: 제목·부제·체크. 탭 시 미리듣기+선택.
  • 하단 액션: 기기 알람음 선택 · 가져오기 · 녹음하기. 커스텀 항목 삭제 지원.
  • 진입 경로에 따라 전역 기본 사운드 또는 특정 알람 사운드를 편집.

4.6친구

  • 섹션 순서: 받은 친구 요청 → 보낸 친구 요청 → 받은 알람 권한 요청 → 보낸 알람 권한 요청 → 친구 목록("서로의 도착을 지켜봐 주는 사이예요").
  • 친구 카드 확장: 알람 보내기 · 권한 요청 · 차단 · 삭제. 권한 상태 배지.
  • 친구 검색 시트(2글자 이상), 초대 카드(카카오톡 공유/링크 복사). 빈 상태 "아직 친구가 없습니다."

4.7마이

  • 프로필 카드(닉네임 변경), 통계 3종, 설정 그룹(알림 설정·위치 권한·사운드 관리·고객센터), 로그아웃, 버전 표기.

4.8도착 알람 화면

  • 잠금화면 위 표시·화면 자동 켜짐·꺼짐 방지. 로고 + "목적지에 도착했어요" + 별칭·주소 + "알람 끄기".
  • 알람 끄기 → 소리·진동 정지, 알림 제거, 화면 종료.

5. 핵심 정책 및 동작 규칙

5.1반경 · 도착 판정

  • 반경 옵션: 100m / 300m / 500m(기본) / 1km / 3km / 10km (시스템 허용치 0.1~50km. 10m·50m는 GPS 정확도보다 작아 제외).
  • 도착 = 목적지까지 거리 ≤ 반경 + GPS 정확도 버퍼(위치 정확도 기반, 최대 50m).
  • 이동 선분 보조 판정: 직전 위치→현재 위치 선분이 목적지 반경을 통과했으면 도착 처리(두 위치 간격 300초 이내, 선분 10km 이내일 때만).

5.2알람 상태 전이

생성(활성) → [도착 발동] → 일반 알람: 비활성화 + 목록 유지(삭제하지 않음 — 재사용·즐겨찾기 가능)
                 → 반복(계속 유지) 알람: 활성 유지 → 반경 이탈 시 재무장 → 재진입 시 재발동
활성 토글은 항상 동기화 대기 플래그와 함께 기록되어, 서버의 이전 값으로 되돌아가 "껐는데 다시 켜지는" 문제를 차단한다.

5.3위치 프라이버시 원칙

  • 위치 수집·근접 판단·알람 발동·확인은 알람 소유자(울릴 사람) 기기 로컬에서만 수행한다.
  • 서버·FCM·로그에 위치, 근접, 도착, 알람 발생/확인 정보를 일절 기록하지 않는다. 서버에는 알람 "설정값"(목적지 좌표·주소·반경 등)만 저장된다.
  • 대리 알람 요청자는 상대의 위치·도착 여부를 알 수 없다. 요청자에게는 권한 상태(대기/수락/거절)만 노출된다.

5.4대리 알람 권한 규칙

  • 알람 전송은 상대가 권한을 수락한 경우에만 가능(서버 RLS로도 강제 — §7).
  • 권한은 요청→수락/거절 상태를 가지며 만료 없음(영구). 사운드는 앱 번들 사운드만 전파된다.
