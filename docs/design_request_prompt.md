# 다왔어(Wakepoint) 리디자인 시안 요청 프롬프트

> 사용법: 아래 프롬프트 전문을 복사해 클로드 디자인에 붙여넣고,
> **앱 화면 캡쳐본**(화면별 1장)과 **역기획서 PDF**(docs/다왔어_역기획서_v1.0.pdf)를 함께 첨부한다.
> 캡쳐본 파일명은 프롬프트의 화면 번호와 맞추면 가장 정확하게 전달된다.

---

당신은 모바일 프로덕트 디자이너입니다. 실제 운영 중인 Android 앱 **"다왔어(Wakepoint)"**의
현재 화면 캡쳐본과 기능 명세(첨부 PDF)를 기반으로, **기존 디자인을 대체할 수 있는 새로운 디자인 시안**을 제안해 주세요.
기존 디자인을 수선하는 수준이 아니라, 같은 기능·같은 정보 구조 위에서 완전히 다른 룩앤필의 시안을 받고 싶습니다.

## 1. 서비스 요약

- 위치 기반 **도착 알람** 앱: 목적지와 반경(100m~10km)을 정해두면, 기기가 반경에 진입할 때 전체화면 알람(소리·진동)으로 깨워준다.
- 핵심 차별점: ① 화면이 꺼져 있어도 뚫고 나오는 전체화면 알람 ② **친구가 내 알람을 대신 설정**해주는 관계 기능("지켜봐 주는 친구") ③ 위치 판정은 100% 기기 로컬 — 서버에 위치·도착 정보를 남기지 않음.
- 주 사용 맥락: **대중교통에서 졸거나 딴짓하는 중**. 흔들리는 차 안, 한 손 조작, 급하게 끄는 상황이 많다.
- 타깃: 통근·통학자, 여행자, 가족·연인을 챙겨주는 사용자. 전 연령. UI는 한국어 단일.

## 2. 첨부물

1. **화면 캡쳐본** — 현재 디자인 기준선:
   - 01 스플래시 / 02 로그인 / 03 회원가입
   - 04 지도 홈(메인) / 05 알람 설정 바텀시트 / 06 알람 목록
   - 07 친구 / 08 마이 / 09 사운드 목록 / 10 도착 알람 전체화면
2. **역기획서 PDF** — 기능 정의 43개(우선순위 포함), 화면별 상세 명세, 정책(반경·알람 상태 전이·권한), 데이터 모델. 화면에 반드시 담겨야 하는 요소는 이 문서의 §3(기능 정의)과 §4(화면 명세)를 기준으로 해주세요.

## 3. 현재 디자인 시스템 (참고용 기준선)

- 컬러: Primary `#0066CC`(블루), 배경 `#F5F5F7`, 카드/시트 `#FFFFFF`, 텍스트 `#171719`, Success `#10B981`, Danger `#EF4444`
- 타이포: Spoqa Han Sans Neo (Thin~Bold)
- 형태 언어: 흰 카드 + 라운드 코너, **플로팅 하단 탭 바**(지도·알람·친구·마이 4탭, 알약형), 바텀시트 기반 입력, 파란 필 버튼
- 전체적으로 밝고 무난한 유틸리티 톤 — 이 "무난함"에서 벗어난 시안을 원합니다.

## 4. 유지해야 하는 것 (변경 금지)

- 정보 구조: 4탭(지도/알람/친구/마이) + 서브 화면(회원가입, 사운드 목록) + 독립 전체화면 알람
- 각 화면의 기능 요소(기획서 §4 기준). 예: 알람 설정 시트의 별칭·반경 6단계·소리·진동, 알람 카드의 활성 스위치·즐겨찾기·"계속 유지", 친구 화면의 요청/권한 섹션 구조
- 한국어 문구(기존 카피 그대로 사용), Android Material3/Compose로 구현 가능한 수준의 표현

## 5. 요청 사항 — 서로 다른 컨셉 3안

같은 화면 세트에 대해 **뚜렷하게 구분되는 3가지 디자인 컨셉**을 제안해 주세요. 방향은 자유지만, 예를 들어:

- A안 **"새벽 첫차"** — 다크 베이스. 야간·새벽 이동과 졸음 맥락에 맞춘 저자극 다크 UI, 알람 순간만 고대비로 폭발하는 구성
- B안 **"여정 카드"** — 목적지·이동을 티켓/카드 메타포로 표현하는 감성 지도 중심 디자인, 지도가 배경이 아니라 주인공
- C안 **"세이프티 기어"** — 알람이라는 안전장치의 신뢰감을 주는 굵은 타이포·강한 컬러 블록·큰 터치 타깃의 고대비 유틸리티 디자인

각 컨셉은 위 예시를 그대로 따르지 않아도 되지만, **서로 다른 사용자 인상**을 남겨야 합니다.

## 6. 컨셉별 산출물

각 컨셉마다:

1. **디자인 토큰**: 컬러 팔레트(라이트+다크), 타이포 스케일, 코너/그림자/간격 규칙
2. **핵심 화면 시안 6장**: ① 지도 홈 ② 알람 설정 바텀시트 ③ 알람 목록(알람 2~3개 상태) ④ 도착 알람 전체화면 ⑤ 친구 ⑥ 로그인
3. **핵심 컴포넌트**: 하단 탭 바, 알람 카드(컴팩트/확장), 반경 선택기, 버튼/스위치, 다이얼로그
4. 컨셉 의도 설명 2~3문장

## 7. 특히 공들여 볼 화면

- **도착 알람 전체화면(10)**: 잠에서 깬 사람이 0.5초 안에 상황을 이해하고 한 손으로 끌 수 있어야 함. 현재는 로고+텍스트+버튼뿐이라 가장 개선 여지가 큼.
- **지도 홈(04)**: 지도 위 검색바·현위치 FAB·"알람 만들기" 버튼·플로팅 탭 바가 겹쳐 복잡함. 지도 가시성과 조작 위계를 다시 설계해 주세요.
- **알람 목록(06)**: 활성/지난/즐겨찾기 상태 구분이 한눈에 안 들어옴. 상태별 시각 언어를 강화해 주세요.

## 8. 제약 및 평가 기준

- 접근성: 본문 대비 4.5:1 이상, 핵심 터치 타깃 48dp 이상, 흔들리는 차 안에서 오조작 방지
- 지도(Google Maps) 위 UI는 지도 스타일 커스텀 가능 전제로 제안 가능
- 평가 기준: ① 알람 앱으로서의 즉각적 이해도 ② 기존과의 차별성 ③ Compose 구현 현실성 ④ 라이트/다크 일관성

먼저 3개 컨셉의 방향과 토큰을 요약해 보여주고, 제가 고른 컨셉부터 화면 시안을 진행해 주세요.
