## 설계 결정
- **로컬 전용**: 주소·좌표는 기기 밖으로 나가지 않음(계획서 제약 — Supabase 신규 테이블 권한 없음).
  공유 이름만 Phase 4 친구 알람에서 노출 예정.
- **집 슬롯**: 별도 엔티티가 아닌 `isHome` 플래그. 이름 "집" 고정, 삭제 불가, 목록 최상단.
  미등록이면 "집 등록 (막차 알람에 쓰여요)" 행으로 유도(Phase 5 막차의 도착지 선행 조건).
- **공유 이름 자동 제안**: 공개 ON 순간 비어 있으면 겹치지 않는 "장소 N" 자동 채움 —
  주소가 유추되는 이름을 쓰지 않게 유도.
- 편집 시 주소 재검색은 막음(명세 2-2 주소 잠금). 위치를 바꾸려면 삭제 후 재등록.
