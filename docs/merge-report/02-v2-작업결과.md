## 1. 개요
v2 통합 명세의 **UI 화면 17개 항목(P1~P17)을 전부 구현**. 각 항목마다
`./gradlew :app:assembleDebug` 통과 후 커밋. 최종 클린 빌드 **BUILD SUCCESSFUL(exit 0)**.

**격리 전략**: v1.5 세션과의 충돌을 피하려 v2는 전부 **신규 파일**로 작성 —
신규 패키지 `com.wakepoint.app.feature.v2/**` + 신규 토큰 파일(`ColorV2`/`SizeV2`/`TypeV2`).
기존 추적 파일 수정 0개 → 소스 병합 충돌 사실상 없음.

## 3. 하드코딩 검사(v1.5 강제 규칙 준수)
- v2 UI 코드 스페이싱/타이포 **`.sp` 리터럴 0건**(`.sp`는 토큰 `TypeV2.kt`에만).
- `.dp` 34건은 전부 허용 예외(테두리 1.5/2dp · 아이콘 14~28dp · 다이얼로그 구조 원 64dp).

## 4. 미구현/최소구현 범위 (명세 추측 금지 원칙)
UI 시안 기반 명세라 백엔드/외부연동은 명세에 없어 **최소 스텁** 처리:
- 날짜/시각/요일 **피커 컴포넌트** 미명세 → 필드는 표시/선택 상태만.
- 과거시각 판정(`timeIsPast`)은 파라미터 주입(실판정은 뷰모델/피커 몫).
- **카카오맵 연동**(경로/택시비/막차시각), FCM 친구알람 송수신, Supabase 동기화, Room 영속성 → 미연결.
- 기존 화면/네비로의 **최종 통합·배선**은 후속으로 남김(→ 병합 문서 §크리티컬).
