|---|---|---|

| 알람 울림 | 문구가 "도착했습니다 / 알람 중지" 가 아니라 "목적지에 도착했어요 / 알람 끄기" | 디자인의 자리 표시 문구로 기존 `strings.xml` 값을 덮어쓰지 않는다. |
| 알람 울림 | 펄스 원의 모프 애니메이션 없음 | 명세에 없는 동작을 추가하지 않는다. 정지 상태의 3겹 원만 그렸다. |
